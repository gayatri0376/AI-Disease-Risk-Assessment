# Anemia Screening System — Backend API Documentation

This document describes the REST API endpoints available for frontend integration (React, Vue, mobile apps, or HTML/JS).

**Base URL**: `http://127.0.0.1:8000`

---

## 1. Unified Patient Screening API (Main Endpoint)

This is the primary endpoint for the frontend. In a single call, it:
1. Saves or links the patient in MySQL.
2. Saves all 14 CBC parameters to the blood report table.
3. Runs the ML Random Forest model (Binary Screening + Multiclass Diagnosis).
4. Saves the results and generates clinical recommendations.
5. Returns the complete report in JSON.

* **Endpoint**: `POST /api/screen-patient/`
* **Headers**: `Content-Type: application/json`

## 2. Direct Machine Learning Endpoints

* **Health Check**: `GET /api/ml/health/`
  * Checks that the ML prediction engine is active and loaded.
* **Direct Screening**: `POST /api/ml/screening/`
  * Runs binary screening (Healthy vs Anemic) directly without saving to the database.
* **Direct Diagnosis**: `POST /api/ml/diagnosis/`
  * Runs 9-class multiclass diagnosis classification directly.

---

## 3. Database Records Endpoints

* **List Patients**: `GET /api/patients/`
* **Patient Details**: `GET /api/patients/{id}/`
* **List Blood Reports**: `GET /api/blood-reports/`
* **Screen Existing Report**: `POST /api/blood-reports/{id}/screen/`
* **Diagnosis Reports**: `GET /api/diagnosis-reports/`
* **Recommendations**: `GET /api/recommendations/`
